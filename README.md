# Информатика для первокурсника

## О проекте
Мини-справочник для студентов первого курса по информатике.

- **Цель:** систематезировать базовые понятия и алгоритмы решения типовых задач.
- **Автор:** Студент группы ИВБ-615 Синичкин Дмитрий
- **Выбранная тема:** Системы счисления

## Список файлов
- 'README.md' - описание проекта, цель, автор, список файлов и инструкция чтения.
- 'glossary.md' - словарь терминов по теме системы счисления.
- 'examples.md' - разобранные примеры задач с ходом решения и ответом.
- 'sources.md' - список использованных источников с описанием.
- '.gitignore' - правила исключения временных файлов из папки 'scratch'.

## Инструкция чтения !!
Изучайте файлы последовательно: сначала ознакомьтесь с терминологией в 'glossary.md', затем переходите к практическим задачам в 'examples.md', а для дополнительного изучения обратитесь к материалам из 'sources.md'.

## Как пользоваться справочником !!
Для эффективного изучения темы придерживайтесь следующего порядка чтения:
1. Начните с `README.md`, чтобы понять структуру проекта.
2. Изучите базовые понятия и определения в `glossary.md`.
3. Разберите пошаговые алгоритмы решения задач в `examples.md`.
4. При необходимости углубить знания обратитесь к списку литературы в `sources.md`.

## Самопроверка !!
После изучения материалов проверьте свои знания с помощью файла [questions.md](questions.md).
